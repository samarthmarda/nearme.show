# Social system status

MVP implemented: unique case-insensitive usernames, scrypt password hashes, login/logout, HttpOnly SameSite session cookie, friend lookup/add by username, online presence, private rooms/code join, online friend invite, shared game state and sanitized-by-React text chat with basic rate limiting. The demo intentionally uses plain colored dots instead of face avatars.

Still needed for production: email verification/reset, formal request/accept/decline/block/report flows, durable presence, presence expiry, robust abuse/rate limits, notifications, moderation/admin audit, room reconnection and persistent chat. Donation, concession and normal trade are not implemented yet.
